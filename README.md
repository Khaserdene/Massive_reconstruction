# 3DGS Offline Data Collector

Энэхүү төсөл нь гар утасны камераас видео дүрсийг (цуврал зураг хэлбэрээр) дотоод сүлжээгээр PC рүү стрийм хийж, 3D Gaussian Splatting (3DGS) сургах дата бэлтгэх зориулалттай.

## 1. Серверийг асаах
PC дээрээ доорх командыг ажиллуулж веб серверийг асаана:
```cmd
cd d:\Massive_reconstruction\server
..\venv\Scripts\uvicorn main:app --host 0.0.0.0 --port 8000
```
*(Эсвэл `uvicorn main:app --host 0.0.0.0 --port 8000` гэж шууд ажиллуулна)*

## 2. Утаснаасаа холбогдох
Утас болон PC тань **нэг WiFi** сүлжээнд холбогдсон байх шаардлагатай.
1. PC-нийхээ IP хаягийг олж мэднэ (Жишээлбэл: `192.168.1.5`).
2. Утасныхаа хөтчөөр (Chrome эсвэл Safari) дараах хаяг руу орно:
   `http://192.168.1.5:8000`
3. **АНХААР:** Chrome зэрэг хөтчүүд нь `http` үед камер ашиглахыг хориглодог. Үүнийг тойрохын тулд утасныхаа Chrome хөтөч дээр:
   - `chrome://flags` гэж орох
   - `Insecure origins treated as secure` гэж хайх
   - Тэнд `http://192.168.1.5:8000` хаягаа бичээд идэвхжүүлэх (Enable) дарж хөтчөө дахин ачаална.

## 3. Дата цуглуулах
1. Утсан дээрээ хуудас руу ороход камерын дүрс шууд харагдана.
2. **"Start Recording"** товчийг дарснаар дүрсээ PC рүү илгээж эхэлнэ.
3. PC дээрх `data/raw_frames/<session_id>/` хавтас дотор зурагнууд (JPEG) ар араасаа цугларч эхлэхийг харах болно.
4. Объектоо 360 градус тойрч, алгуур хөдөлгөөнөөр зураг авалт хийгээд **"Stop Recording"** дарж дуусгана.

## 4. 3DGS Pipeline (COLMAP + Train)
Та зургаа цуглуулж дууссаны дараа [Оригинал 3D Gaussian Splatting](https://github.com/graphdeco-inria/gaussian-splatting) санг ашиглан моделио сургах боломжтой.

1. **COLMAP боловсруулалт:** 3DGS сангийн `convert.py` ашиглан зурагнуудаасаа камерын байрлал үүсгэнэ.
   ```cmd
   python convert.py -s D:\Massive_reconstruction\data\raw_frames\<цуглуулсан_хавтасны_нэр>
   ```
2. **Модел сургах:**
   ```cmd
   python train.py -s D:\Massive_reconstruction\data\raw_frames\<цуглуулсан_хавтасны_нэр>
   ```
3. **Үр дүнг харах:**
   SIBR viewer ашиглан сургасан моделио нээж харна.
